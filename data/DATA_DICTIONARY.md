# Dataset dictionary

`inventory_demand.csv` is a deterministic, fully synthetic teaching dataset generated by `generate_dataset.py` (seed `20261115`). It contains 6 stores, 5 product categories, and 104 weeks of observations per store/category combination.

The task is to estimate `demand_next_week` from information available when the forecast is made. The final 20 weeks are marked as `test`; earlier weeks are `train`. This chronological split is supplied in the CSV so KNIME and Python can use exactly the same rows.

| Column | Meaning | Type | Model input? |
|---|---|---|---|
| `week_start` | Start date of the forecast-origin week | Date-like text | No; context only |
| `week_index` | Sequential week number used to create the chronological split | Integer | No; split metadata |
| `store_id` | Synthetic store identifier | Categorical | No; identifier intentionally excluded |
| `region` | Store region | Categorical | Yes |
| `store_format` | Small, Standard, or Large store | Categorical | Yes |
| `product_category` | Product category | Categorical | Yes |
| `price_next_week` | Planned price for the forecast week | Numeric | Yes |
| `discount_pct_next_week` | Planned percentage discount | Numeric | Yes |
| `promotion_next_week` | Whether a promotion is planned (0/1) | Integer | Yes |
| `holiday_next_week` | Synthetic holiday indicator (0/1) | Integer | Yes |
| `forecast_month` | Month number for the forecast week | Integer | Yes |
| `previous_week_units` | Units demanded in the most recent completed week | Numeric | Yes |
| `avg_4_week_units` | Average units across the recent history window | Numeric | Yes |
| `demand_next_week` | Target: synthetic demand in the forecast week | Integer | **Target** |
| `split` | `train` or `test` label | Categorical | No; split metadata |

## Important limitations

- Values are simulated; there is no real retailer, customer, or store represented.
- Missing values are intentionally inserted into selected input columns to teach imputation.
- The target is synthetic and designed to have learnable relationships. A good score here does not imply real-world forecasting ability.
- Do not use this dataset or its model for operational inventory decisions.
